## 2. Facts beyond X09 §4 (read by X10)

- `FieldMap::fm_Init` FUN_00464bc0 sets all four `fm_BroadFunc` pointers: `fm_fp_AllInMap1/2` = `so_AllInMapNomal`
  FUN_0054be00 / FUN_0054c370 and `fm_fp_AllOfRange1/2` = `so_AllOfRangeNomal` FUN_0054d360 / FUN_0054c900, or the
  `*MiniHouse` set (FUN_00553c60 / FUN_00553dd0 / FUN_00554100 / FUN_00553f60) when `FieldAttr.KingdomQuestMap` = 2
  (mini-house interior). This settles X09 §4's "*(inferred)* from the names" for the `fm_fp_AllOfRange*` pointers.
  Z09 `zone/Z09-world.md` (the `fm_Init` block and the broadcast-slot table near line 9471 / 9495) already lists them.
- `so_LogoutPacketBroadcast` FUN_00553a40 sends `0x1805` through `so_AllInMap(iterator, 0)`, so to the whole map
  instance on the layer, not "to sight" as Z01 §3.2's example says; skipped when `fm_FieldOption` is null; called a
  second time when the first call returns 0.
- `so_AllInMapNomal` FUN_0054be00 (profiler `so_AllInMapNomal2`; re-read in part 2): walks `so_slantedlist.Ylist`
  both ways with only the layer filter (`LayerRegistInfo` 8-byte layer number equal, or `nViewType` ≠ 0 on either
  side) and passes `so_DistanceSquar(this, obj)` to the visitor without a limit. `so_AllInMap0` FUN_0054b8c0 only
  dispatches through `fm_fp_AllInMap1` when `so_Field` ≠ null. Both as X09 §4 says.
- `so_AllOfRangeNomal` FUN_0054c900 (profiler `so_AllOfRangeNomal_Class2`, the iterator overload, `fm_fp_AllOfRange2`;
  read in part 2; X09 §4 had left it unread): arguments `(eventNumber, centre, radius, fanSector, iterator, flag,
  excludeHandle)`. Pass 1 walks `Xlist` both ways while `|x − centre.x| < radius` and stamps
  `so_slantedlist.eventnumber[g_BroadcastStackPoint] = eventNumber`; pass 2 walks `Ylist` both ways while
  `|y − centre.y| < radius` and calls the iterator for an object that carries the stamp, whose handle ≠
  `excludeHandle`, with distance² **strictly** < radius², inside the fan sector when `fanSector` ≠ null (cosine of
  the half angle via `ShineRadian::sr_cos1024`, compared with the dot product of the unit vector to the object and the
  sector direction; an object on the centre point passes), and on the same layer (same filter as `so_AllInMapNomal`).
  A visitor returning 0 stops the walk. With `flag` set it ends with `iterator(this, this, 0)`. Unlinked object
  (both X neighbours are itself): `"Unlinked object"` to the `MapRearrangeObserver`, return 0. Each walk stops after
  10 000 objects (a `BroadCastLog` line); a self-linked node triggers an assert, vt 0x8a0, and `fm_Relink`.
  The radius is the caller's: `so_AllOfRange_Class1` FUN_0054bc80 replaces 0 by `MapInfo.Sight` (row in §5.4).
